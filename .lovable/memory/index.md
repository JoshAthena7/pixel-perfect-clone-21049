# Project Memory

## Core
IRIS North Star: Truth → Intelligence → Understanding → Strategy → Execution. NOT Vault → Oracle → Studio. IRIS is a connected intelligence graph, not a document library.
Every piece of intelligence maps to one of the 9 Domains and is tagged across 5 dimensions (Mission Domain, Geography, Signal Type, Importance, Time Horizon).
Users only ever see the 5 IRIS Outputs: Mission Brief, Environmental Assessment, What the State Wants, Emerging Risks, Recommended Strategy. Everything else is invisible infrastructure.
Layer 3 Mission Intelligence Graph is THE differentiator — build the graph before building UI on top of it.
Drafts are written in the client's environment, NOT in Athena/Atlas. Cockpit = intel + health checks + scoring + collaboration per question, not a draft editor.
